# Project Workspace Landing Page

A simple and clean Hero Landing Page built using HTML and Tailwind CSS.

## Project Overview

This project is a landing page for a modern AI-powered workspace called Project.

The page includes a sticky navigation bar, hero section, CTA buttons, dashboard preview, floating information cards, and a fixed chat button.

## Technologies Used

- HTML5
- Tailwind CSS
- Tailwind CSS CDN
